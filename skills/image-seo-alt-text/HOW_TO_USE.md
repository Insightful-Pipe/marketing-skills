# How to Use This Skill

Hey Claude, I just added the "image-seo-alt-text" skill. Check the images on my main pages, write the missing alt text, and tell me which image problems cost me Google Images traffic.

## What you need

- **Nothing connected, if you like.** Upload the images or paste image URLs, and say which page each one is on. Claude writes the alt text after looking at each picture. Add a Search Console export (Performance, Search type: Image, the Pages tab) to rank the fixes by traffic.
- **Or the InsightfulPipe MCP connected to Claude.** With Search Console, the Web Crawler and PageSpeed added, the skill finds the pages, the images and their problems itself. Add WordPress if your site runs on it, and the skill can set the alt text in your media library once you say yes.
- **Words to avoid,** if any, such as claims your legal team doesn't allow.

## Example requests

**Alt text for uploaded images**
Hey Claude, I just added the "image-seo-alt-text" skill. Here are six product photos for our ceramic dripper page. Write alt text for each one.

**Image SEO audit**
Hey Claude, I just added the "image-seo-alt-text" skill. Audit the images on our 10 most visited pages and rank the fixes by Google Images clicks.

**Why no Google Images traffic**
Hey Claude, I just added the "image-seo-alt-text" skill. Our product photos get almost no clicks from Google Images. Find out why.

**Fix it in WordPress**
Hey Claude, I just added the "image-seo-alt-text" skill. Write alt text for the images on our blog posts, then update them in WordPress. Show me the list first.

## What you get

1. **A page table:** Google Images clicks and impressions, web clicks, how many images need new alt, wasted image weight and whether the main image is lazy-loaded.
2. **Alt text for every image that needs it,** with the image's role (informative, a link or button, text, a chart or decorative), the problem with the current alt, the new alt and its length. Decorative images get an empty alt on purpose.
3. **Speed fixes per image:** resize, convert to WebP, add width and height, or stop lazy-loading the hero image, with the KB each one saves.
4. **File names** worth changing, and when it is safe to change them.
5. **Image sitemap entries,** only for images Google may not find on its own.
6. **A list of images it couldn't see,** so you can send them. It never writes alt text for an image it hasn't looked at.

## What it can change for you

With your yes on the exact list, it can set the alt text of WordPress media library images. That covers featured images, WooCommerce product galleries, theme images and every future use of those images. Images already placed inside a post or a product description (including block-editor galleries) keep their old alt; the skill lists those for you to change in the editor.

It never renames, converts or uploads files, and it never changes your templates.

## Tips

- Start with the pages that get Google Images impressions but few clicks. That's where better alt text and better images show first.
- Product galleries are the usual weak spot: every photo gets the product name as its alt. Each photo should say what's different about it.
- Run it again a month after the fixes and compare the Google Images clicks.
