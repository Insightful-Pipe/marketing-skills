# How to Use This Skill

Hey Claude, I just added the "ad-specs-asset-matrix" skill. Build the asset matrix for my next campaign and check the files I uploaded against it.

## What you need

- **Nothing connected, if you like.** Name the platforms and placements, upload the files (or list their sizes), and paste the copy. The skill reads width, height, length, file size and type from the uploads.
- **Better: the InsightfulPipe MCP connected to Claude,** with the ad accounts the campaign runs on (Meta, TikTok, LinkedIn, Pinterest, Snapchat, X or Google Ads). The skill then reads which placements the campaign really uses, and where Meta spends, so the matrix holds only the files you need.
- **Optional:** a still or frame from each vertical video, so the safe zones can be checked against where your text and logo really sit.

## Example requests

**Full matrix and file check**
Hey Claude, I just added the "ad-specs-asset-matrix" skill. Build the asset matrix for our launch campaign on Meta, TikTok, LinkedIn and Performance Max, and check the files I uploaded.

**LinkedIn ad specs for one campaign**
Hey Claude, I just added the "ad-specs-asset-matrix" skill. What LinkedIn ad specs do I need for a single image campaign and a video campaign? Here are my files and the intro text.

**TikTok ad specs check**
Hey Claude, I just added the "ad-specs-asset-matrix" skill. Check this TikTok video and ad text against TikTok's ad specs before I upload it.

**Designer handoff**
Hey Claude, I just added the "ad-specs-asset-matrix" skill. Give my designer the list of social media ad sizes to make for this campaign, with the fewest master files.

## What you get

1. **A verdict:** ready to upload, or fix first, with the number of blockers.
2. **The placements** the campaign runs, read from the accounts or taken from you.
3. **The matrix:** every placement and format with its need (required, recommended or optional), the spec, the file that serves it, and the result: covered, covered but cropped, fails or missing.
4. **A production list:** the fewest master files to make or re-export, each with the placements it serves.
5. **File checks, safe zones and text:** every file measured and every line counted against hard limits, published cut points (quoting what readers will see) and recommended lengths.
6. **Gaps ranked:** blockers first, then placements running on a fallback, then readability.

The report prints the date the spec table was read from each platform's own page. Where a page gives no number (such as TikTok's ad text limit) or couldn't be read (X's spec pages), the cell says so and that limit isn't graded: the report tells you which field to read in the platform's preview or ads manager, and grades against the number you give it.

## What it can change for you

Nothing. It only reads placements and media and checks files. You upload the new files yourself, or with a builder skill that shows each change and waits for your yes.

## Tips

- Run it before a launch, and again when you add a platform or switch on automatic placements.
- Upload the real export files, not screenshots: screenshots change the pixel size.
- If your ads manager shows a different limit from the matrix, say so. Platforms change specs, and the skill will use yours.
